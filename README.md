# MultiBEST---Multiscale-Multiphase-Bridging-Experiment-and-Simulation-Toolkit
MultiBEST is a GUI‑based framework that builds experiment‑identical microstructures for atomistic, continuum and multiscale simulations, starting from 2D micrographs, 2D/3D EBSD or sketches, and generating grain‑resolved atomistic models and continuum meshes with explicit grain‑boundary regions.
