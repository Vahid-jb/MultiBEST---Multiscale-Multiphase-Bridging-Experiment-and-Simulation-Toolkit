# Image to Mesh Converter

## Overview
The **Image to Mesh** module is a tool designed for multiscale simulations and computational materials science. It converts arbitrary 2D binary images into high-quality 3D meshes. This tool is particularly useful for generating realistic microstructural models from experimental data or processed images. The final output will be extruded along the direction perpendicular to the figure by an adjustable size. Additionally, one can use several 2D figures which depict sequential slices of a 3D object and make a 3D mesh with specified thickness out of each, then by merging them along the slicing direction, get a reconstructed 3D mesh. The module includes an intelligent alignment step that ensures the bottom surfaces of the Guest, Base, and Bulk phases are perfectly coplanar (aligned at Z=0 relative to the bulk). This facilitates seamless assembly of the phases in downstream applications. As soon as the mesh is generated, its dimensions will be displayed, then the users can manipulate the mesh using operators including Scale factor to obtain the desired dimension. In case a finalized mesh is already available, the user can skip the image generation and apply operators directly on the mesh.

This package serves as a bridge between 2D imaging and 3D finite element (FE) or volume analysis.

## Core Features

### 1. 2D to 3D Conversion
The module utilizes the input image as a displacement texture to generate geometry. It automatically removes "flat" regions to isolate specific phases defined by the image contrast. Finally, it subdivides, extrudes, and cleans up the resulting mesh to ensure valid geometry.

### 2. Phase Generation
The tool automates the creation of three distinct material phases from a single binary image:
- **Guest Phase (Black Regions):** The mesh corresponding to the *black* regions of the input image. In a material context, this might represent inclusions, pores, or a secondary phase.
- **Base Phase (White Regions):** The mesh corresponding to the *white* regions, generated by automatically inverting the input image. This typically represents the matrix.
- **Bulk Phase:** An intact, solid block with the same dimensions as the image.


### 3. Customization & Control
Users can fine-tune the output to their specific needs:
- **Resolution Control:** Choose from four preset mesh densities (`coarse`, `normal`, `fine`, `extra_fine`) to balance detail vs. file size.
- **Output Formats:** Support for industry-standard formats: **STL**, **OBJ**, etc.
- **Extrusion Depth:** Configurable depth (Z-axis thickness) for the 3D model.


## Workflow

The typical workflow for generating a 3D microstructure is as follows:

1.  **Image Acquisition:** Obtain a 2D image of the microstructure (SEM, optical, etc.).
2.  **Image Processing:** Use the 'Image processing' module to convert the raw image into a high-contrast **binary image** (sharp black and white).
    -   **Black:** Represents the *Guest* phase.
    -   **White:** Represents the *Base* phase.
3.  **Mesh Generation:** Run the mesh generation process with the binary image.
4.  **Post-Processing:** The resulting 3D models can be further manipulated (rotated, displaced, scaled).


## Parameters

| Argument | Description | Default |
| :--- | :--- | :--- |
| **Image/Mesh Path** |  Full path to the input binary 2D image. | *Interactive* |
| **Extrusion Depth** |  Thickness of the generated 3D model (Z-axis). | `0.25` |
| **Mesh Density (Vertices)** | Resolution of the mesh. Options: `coarse`, `normal`, `fine`, `extra_fine`. | `fine` |
| **Output Format and Directory** | File format for the 3D mesh. Options: `STL`, `OBJ`, etc. Directory where the files will be saved. | `STL` |
| **Phases** | Guest: Generate the mesh for the black regions. <br>  Base: Generate the mesh for the white regions. <br> Bulk: Generate the solid bulk block. |
| **Mesh Operators** | Rotate (degree) Displace (no unit) Scale. | `0` |- |

Mesh generation writes its parameters to `input_image_to_mesh.txt` and the mesh operators write theirs to `input_rescale.txt`, both in the output directory. The backends read them from there, so a run can be repeated or edited outside the GUI with `Image_to_Mesh.py --input-file input_image_to_mesh.txt` or `rescale.py --input-file input_rescale.txt`.

---

## Notes
The script applies a scale factor of `0.01` to pixel dimensions (100 pixels = 1 Unit).<br>

To generate a two-dimensional mesh, simply assign a value of zero to the Z-axis scale factor.<br>

For complex geometries, we would suggest subtracting the Guest or Base phase from the Bulk phase to achieve a perfect inversion or complementary geometry, ensuring watertight meshes suitable for FE simulations.<br>

The core part of mesh generation from a figure is developed using the [Blender Python API](https://docs.blender.org/api/current/index.html).
